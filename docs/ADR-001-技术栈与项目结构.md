# ADR-001：技术栈与项目结构

- 状态：已接受（2026-09-08）
- 背景：需要实现 Windows 端口监控工具 PortLite，界面与交互参照设计稿（统计卡片、搜索/筛选、连接表格、结束进程）。

## 决策

基于现有 `port-view` 项目（Tauri 2 官方模板）实施，采用以下技术栈：

| 层次 | 选型 | 说明 |
|---|---|---|
| 桌面框架 | Tauri 2 | 轻量、Rust 后端可直连 WinAPI |
| 前端框架 | Vue 3（`<script setup>` SFC） | 项目现状 |
| 语言 | TypeScript（strict） | 项目现状 |
| 构建 | Vite（保留已装 Vite 8） | 与模板一致，功能无差异 |
| 样式 | UnoCSS（preset-wind3） | 原子化样式，贴合设计稿 |
| 状态管理 | Pinia | 连接数据 + 筛选状态 |
| 组件库 | naive-ui | 表格、输入框、选择器、标签、气泡确认 |
| 拼音 | pinyin-pro | 为中文软件名/进程名生成拼音索引 |
| 权限 | 管理员运行（requireAdministrator） | 见 ADR-003 |

## 后果

- 项目保留 `src/`（前端）与 `src-tauri/`（Rust）标准分层。
- 产品命名保持 `port-view`（窗口标题、二进制名、identifier 均不更改）。
- 界面语言为中文。

## 更新（2026-09-09）

- 构建工具以 `package.json` 实际锁定版本为准：**Vite 8**（`@vitejs/plugin-vue` 6、UnoCSS 66 / preset-wind3、TypeScript 6、vue-tsc 3）。
- 产品展示名统一为 **Port Process View**（窗口标题 / index.html / Hero 大标题），内部包名、二进制名仍为 `port-view`。
- 界面支持**中 / 英双语切换**（默认中文，见 ADR-004 国际化条目），并非仅中文。
- 新增能力对应的 Rust 依赖：`Win32_System_ProcessStatus`（内存）、`Win32_System_Threading`（CPU 时间/进程路径）、`Win32_Graphics_Dwm`（窗体圆角）；前端新增 `@tauri-apps/plugin-opener`（打开外链）与 pinyin-pro（拼音搜索）。
