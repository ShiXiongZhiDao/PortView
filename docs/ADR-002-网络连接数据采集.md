# ADR-002：网络连接数据采集

- 状态：已接受（2026-09-08）
- 背景：需枚举系统全部 TCP/UDP 连接及监听端点，并附带进程名、进程路径、软件名，用于表格展示与模糊搜索。

## 决策

Rust 侧使用 Windows API 直接采集，暴露一个 Tauri command：

- `get_connections() -> Vec<ConnectionInfo>`
  - TCP：`GetExtendedTcpTable(..., TCP_TABLE_OWNER_PID_ALL, AF_INET)`，结构体 `MIB_TCPROW_OWNER_PID`（状态/本地地址/本地端口/远程地址/远程端口/属主 PID）。端口按网络字节序读取（`u16::from_be`）。
  - UDP：`GetExtendedUdpTable(..., UDP_TABLE_OWNER_PID, AF_INET)`，结构体 `MIB_UDPROW_OWNER_PID`（本地地址/本地端口/属主 PID）。UDP 无状态，远程地址为空，状态显示 `-`。
  - 进程名/路径：`OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `QueryFullProcessImageNameW`；失败（如进程已退出）时降级为进程名取 PID、路径留空。
  - 软件名：`GetFileVersionInfoW` + `VerQueryValueW` 读取 exe 版本资源（优先 `FileDescription`，回退 `ProductName`）；读取失败时返回空。
  - 本地/远程地址格式为 `IP:端口`（IPv6 地址带 `[]`，`0.0.0.0`/`::` 保留原样）。
- 每次调用为一次性快照；前端负责刷新频率与筛选。

## 后果

- 数据在 Rust 侧一次取全，前端对 ~500 条数据做本地过滤/统计，无需反复 IPC。
- 取进程路径与软件名需要管理员权限（详见 ADR-003），普通权限下部分系统进程信息降级。
- 仅支持 IPv4 连接表；IPv6 连接不在当前版本范围（与设计稿一致，后续可扩展 `AF_INET6`）。
