# ADR-003：进程终止与权限模型

- 状态：已接受（2026-09-08）
- 背景：表格每行提供"结束进程"操作；工具需要显示所有进程完整路径并允许终止系统进程。

## 决策

- **权限**：应用以管理员权限运行（Windows manifest `requestedExecutionLevel = requireAdministrator`），保证路径可见性与进程可终止性。启动时出现一次 UAC 提权提示。
- **终止机制**：Rust 侧调用系统命令 `taskkill /F /PID <pid>`（`std::process::Command`），返回成功/失败信息；失败（拒绝访问、进程不存在等）将系统错误信息透传给前端提示。
- **安全确认**：前端"结束进程"按钮使用 naive-ui 气泡确认（`n-popconfirm`），显示进程名 + PID，确认后才发起终止；系统关键进程（如 `System` PID 4、`svchost.exe` 等）额外红色警示文案。终止完成后自动触发一次刷新。

## 后果

- 误点风险由确认框 + 警示文案缓冲。
- 管理员权限是使用该工具的必要条件；非管理员运行时结束系统进程会失败并得到明确提示。
