# ADR-004：前端交互模型

- 状态：已接受（2026-09-08）
- 背景：设计稿要求统计卡片、搜索、协议/状态筛选、连接表格、手动刷新、更新时间与"当前显示 N 条"。

## 决策

- **布局**：顶部标题栏（左：WINDOWS PORT WATCHER / port-view；右：刷新按钮 + 主题切换）；四张统计卡片（TCP/UDP/监听端口/进程）；工具栏（搜索框、协议/状态下拉、条数与更新时间）；数据表格。
- **单表合并视图**：进程与连接合并在同一张表格，无需切换。每行一个进程（默认列出系统**全部**进程，含无网络连接的进程，如 Everything），列 = 进程名（+完整路径）、PID、端口（该进程聚合的本地端口摘要，超 6 个折叠）、TCP 数、UDP 数、监听端口数、软件名、操作（结束进程，带确认 + 系统进程警示）；点击行展开显示该进程的全部连接明细（协议/本地端口/本地地址/远程地址/状态）。数据源 `get_processes()`（ToolHelp 枚举 + 连接聚合）与 `get_connections()`（展开明细）。
- **统计口径**：TCP = TCP 连接总数（含 LISTENING）；UDP = UDP 端点总数；监听端口 = LISTENING 状态条目数；进程 = 全部进程数。
- **搜索**：输入即实时过滤（防抖 ~200ms），子串模糊匹配，命中字段 = 进程名、PID、路径、软件名、拼音（中文软件名/进程名的全拼与首字母，由 pinyin-pro 预计算索引）、端口。
- **筛选**：协议（全部/TCP/UDP）与状态（全部/LISTENING/ESTABLISHED/TIME_WAIT/CLOSE_WAIT/其他）下拉映射到进程维度（仅显示含有该类连接/状态的进程），与搜索叠加生效；"当前显示 N 个进程"实时更新。
- **刷新**：仅手动刷新（标题栏绿色"刷新"按钮），进程与连接一并刷新；右上角显示最近更新时间；"结束进程"完成后自动刷新一次，保证终止结果即时可见。
- **主题**：naive-ui 主题三态——跟随系统 / 暗色 / 亮色，持久化到 localStorage。

## 后果

- 所有筛选与统计在前端完成（数据一次性取回），IPC 仅用于获取快照与终止进程。
- 刷新期间保留旧数据展示，避免表格闪烁；数据量大时（>1000 条）表格开启虚拟滚动。
