# ADR-004：前端交互模型

- 状态：已接受（2026-09-08）
- 背景：设计稿要求统计卡片、搜索、协议/状态筛选、连接表格、手动刷新、更新时间与"当前显示 N 条"。

## 决策

- **布局**：顶部标题栏（左：WINDOWS PORT WATCHER / PortLite；右：刷新按钮 + 主题切换）；四张统计卡片（TCP/UDP/监听端口/进程）；工具栏（搜索框、协议下拉、状态下拉、条数与更新时间）；数据表格。
- **统计口径**（基于全部数据，不随筛选变化）：
  - TCP = TCP 连接总数（含 LISTENING）
  - UDP = UDP 端点总数
  - 监听端口 = LISTENING 状态条目数
  - 进程 = 涉及全部连接的去重进程数（去重 PID）
- **搜索**：输入即实时过滤（防抖 ~200ms），子串模糊匹配，命中字段 = 端口、进程名、PID、路径、软件名、拼音（中文软件名/进程名的全拼与首字母，由 pinyin-pro 预计算索引）。
- **筛选**：协议（全部/TCP/UDP）与状态（全部/LISTENING/ESTABLISHED/TIME_WAIT/CLOSE_WAIT/其他）下拉，与搜索叠加生效；"当前显示 N 条"实时更新。
- **表格**：列 = 协议、本地端口、本地地址、远程地址、状态、进程（进程名 + 路径两行）、PID、操作；LISTENING 用绿色标签，其余状态灰色标签，UDP 状态显示 `-`；点击列头排序（本地端口/状态/PID 等可排）。
- **刷新**：仅手动刷新（标题栏绿色"刷新"按钮）；右上角显示最近更新时间；"结束进程"完成后自动刷新一次，保证终止结果即时可见。
- **主题**：naive-ui 主题三态——跟随系统 / 暗色 / 亮色，持久化到 localStorage。

## 后果

- 所有筛选与统计在前端完成（数据一次性取回），IPC 仅用于获取快照与终止进程。
- 刷新期间保留旧数据展示，避免表格闪烁；数据量大时（>1000 条）表格开启虚拟滚动。
