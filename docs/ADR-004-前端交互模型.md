# ADR-004：前端交互模型

- 状态：已接受（2026-09-08）
- 背景：设计稿要求统计卡片、搜索、协议/状态筛选、连接表格、手动刷新、更新时间与"当前显示 N 条"。

## 决策

- **布局**：顶部标题栏（左：WINDOWS PORT WATCHER / port-view；右：刷新按钮 + 主题切换）；四张统计卡片（TCP/UDP/监听端口/进程）；工具栏（搜索框、协议/状态下拉、条数与更新时间）；数据表格。
- **单表合并视图**：进程与连接合并在同一张表格，无需切换。每行一个进程（默认列出系统**全部**进程，含无网络连接的进程，如 Everything），列 = 进程名（+完整路径）、PID、端口（该进程聚合的本地端口摘要，超 6 个折叠）、TCP 数、UDP 数、监听端口数、软件名、操作（结束进程，带确认 + 系统进程警示）；点击行展开显示该进程的全部连接明细（协议/本地端口/本地地址/远程地址/状态）。数据源 `get_processes()`（ToolHelp 枚举 + 连接聚合）与 `get_connections()`（展开明细）。
- **统计口径**：TCP = TCP 连接总数（含 LISTENING）；UDP = UDP 端点总数；监听端口 = LISTENING 状态条目数；进程 = 全部进程数。
- **搜索**：输入即实时过滤（防抖 ~200ms），子串模糊匹配，命中字段 = 进程名、PID、路径、软件名、拼音（中文软件名/进程名的全拼与首字母，由 pinyin-pro 预计算索引）、端口。
- **筛选**：协议（全部/TCP/UDP）与状态（全部/LISTENING/ESTABLISHED/TIME_WAIT/CLOSE_WAIT/其他）下拉映射到进程维度（仅显示含有该类连接/状态的进程），与搜索叠加生效；"当前显示 N 个进程"实时更新。
- **刷新**：仅手动刷新（标题栏绿色"刷新"按钮），进程与连接一并刷新；右上角显示最近更新时间；"结束进程"完成后自动刷新一次，保证终止结果即时可见。
- **主题**：naive-ui 主题三态——跟随系统 / 暗色 / 亮色，持久化到 localStorage。
- **布局（紧凑列表，贴纸风格）**：顶部 Hero 区（绿色 logo + 大标题 + 描述 + 搜索框 + 主题切换 + 刷新按钮 + 底部 4 项数字统计条）→ 筛选条（协议/状态）→ 进程列表（单个贴纸卡片容器 + sticky 表头：进程/PID/TCP/UDP/监听/端口/状态/操作；每行一个进程，点击"连接"在该行下方展开连接明细，同时只展开一个；无分页，滚动浏览）。
- **视觉风格（LearnHub / educational-platform，由 UI/UX Pro Max 技能指导）**：参考 `https://uupm.cc/demo/educational-platform`——扁平清新：米白背景 + 纯白卡片 + 轻阴影 + 鲜绿主色 + pill 标签/按钮；Fredoka（标题/数字）+ Nunito（正文）本地字体；亮色=米白底绿主色，暗色=深蓝灰变体；设计 token 见 `docs/design-system/MASTER.md`。
- **主题状态共享**：`src/composables/useTheme.ts` 模块级单例管理 themeMode/isDark，App.vue / HeroHeader / ProcessCard 共享同一份状态，避免切换不同步；同时同步 `<html data-theme>`，保证 teleport 到 body 的 n-modal 弹窗也能继承主题 CSS 变量。
- **国际化（中/英）**：`src/i18n/index.ts` 模块级单例（lang + t()，持久化 localStorage 键 `port-view-lang`，默认中文），全部界面文案走字典，切换语言实时重渲染；状态枚举（LISTENING 等）保持英文不译。
- **设置页（SettingsModal）**：齿轮图标按钮触发，分区为外观主题（跟随系统/亮/暗）、界面语言（简体中文/English）、代码仓库（GitHub/Gitee 按钮，经 `@tauri-apps/plugin-opener` 在系统浏览器打开 https://gitee.com/ShiXiongZhiDao/port-view，浏览器环境回退 window.open）、赞助支持（支付宝/微信二维码，图片位于 `public/qr/`，n-image 点击放大）、关于（版本号）。
- **应用命名**：界面标题与窗口标题统一为 "Port Process View"（tauri.conf.json window.title、index.html title、Hero 大标题）。
- **无边框窗口 + 交通灯**：`tauri.conf.json` 设 `decorations:false` 去掉原生标题栏；前端 `TitleBar.vue` 提供可拖拽区（`data-tauri-drag-region`，需 `core:window:allow-start-dragging` 等权限）与右侧 macOS 风格交通灯（黄=最小化、绿=最大化/还原、红=关闭，hover 显示符号），经 `@tauri-apps/api/window` 控制窗口，浏览器环境安全兜底。
- **窗体圆角**：Windows 11 由 Rust 侧 `DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE=DWMWCP_ROUND)` 设置系统圆角；同时窗口 `transparent:true`、html/body/naive bodyColor 全部透明，由 App 根容器以 14px 圆角 + `--pv-bg` 底色裁出窗体形状，圆角半径可控且 Win10/浏览器下也成立。
- **设置页 Tab 化**：SettingsModal 分通用/仓库/升级/赞助/关于五个 Tab，内容区固定高度（336px）避免切换时弹窗尺寸跳动。
- **升级检查**：`composables/useUpdate.ts` 模块级单例，请求 Gitee Releases API（`/releases/latest`）做语义版本对比；HTTP 404（尚未发布 Release）视为"已是最新"，网络/5xx 才报错；发现新版本显示版本号、更新说明与"下载最新版"（opener 打开 Release 页）。
- **资源列与排序**：进程列表在 PID 后展示 CPU、内存两列（采集算法与口径见 ADR-005）；两列表头可点击排序（降序↔升序），默认按内存从大到小；CPU 按占用暖色分级。
- **最终布局（覆盖早期描述）**：最顶部为可拖拽的自定义标题栏 `TitleBar`（右侧交通灯）；其下 Hero 区 = 左 logo+标题"Port Process View"+描述、右侧 TCP/UDP/监听/进程四个彩色统计块 + 齿轮设置；再下 FilterBar = 协议/状态下拉，右侧搜索框 + 刷新（无"筛选"字样标签）；最下 ProcessList 单贴纸容器列表（表头：进程/PID/CPU/内存/TCP/UDP/监听/端口/状态/操作），行内点"连接"展开明细。

## 后果

- 所有筛选与统计在前端完成（数据一次性取回），IPC 仅用于获取快照与终止进程。
- 刷新期间保留旧数据展示，避免表格闪烁；数据量大时（>1000 条）表格开启虚拟滚动。
